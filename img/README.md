# Tracker images (GM-set)

Drop image files here and commit them. The tracker loads them by filename — no upload
buttons, so only you (the repo owner) can set them. `.png` or `.jpg` both work.

## Character portraits
Name each file after the character id:

| File            | Character   |
|-----------------|-------------|
| `cal.jpg`       | Cal Kestis  |
| `bode.jpg`      | Bode Akuna  |
| `tann.jpg`      | Tann        |
| `gibbs.jpg`     | Gibbs       |
| `pike.jpg`      | Pike        |
| `merrin.jpg`    | Merrin      |
| `kata.jpg`      | Kata Akuna  |
| `bd1.jpg`       | BD-1        |
| `alpha.jpg`     | Alpha       |

## Ship
| File         | Shows as        |
|--------------|-----------------|
| `ship.jpg`   | Mantis card art |

## Scene / ambience
| File          | Shows as               |
|---------------|------------------------|
| `scene.jpg`   | Location banner image  |

Any file you leave out simply shows no image for that slot (same as an empty portrait
today) — nothing breaks. Images are ~640px max in the app, so anything from ~500px up
looks fine; keep them reasonably sized so the page loads fast.
